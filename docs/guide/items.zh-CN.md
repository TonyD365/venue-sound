# 物品大全

VenueSound 添加的每一个物品和方块：用途、合成配方、怎么摆放、控件和接口。想看简短的总览，见
[设备一览](devices.md)（英文）；调音台各控件的详细说明见 [调音台](console.md)（英文）。

阅读说明：

- **朝向**：除非另有说明，设备放下时正面朝向你。
- **接口**：蓝色圈是 **IN**（输入），红色圈是 **OUT**（输出）。用任意线材插接（见
  [接线](cabling.md)，英文）。
- **控件**：按钮和开关直接右键；旋钮点左半边调小、点右半边调大；推子按住右键再移动准星拖动。
  鼠标滚轮可以把准星下的旋钮或推子每格转一档。
- **配方**：3×3 工作台，`.` 表示空格。所有物品也都能在创造模式的 **VenueSound** 物品栏里拿到。

## 信号源

### 无线麦克风

手持无线麦，就是歌手或主持人拿在手里的那种。拿在手上时，你的声音会传到 128 格内所有同通道的
无线接收器。

**配方**（得 1 个）：

```
. B .
. R .
. K .
```

B = 铁栏杆，R = 红石粉，K = 黑色混凝土。

**用法**：拿在主手或副手上说话（通过 Simple Voice Chat）。它不能放置。

| 操作 | 作用 |
|---|---|
| 右键 | 切到下一个通道（1-16，到 16 后回到 1），通道号显示在快捷栏上方 |
| 潜行 + 右键 | 静音 / 取消静音。物品提示里显示"开启"或"已静音" |

**常见接法**：调到某台[无线接收器](#无线接收器)的通道，接收器再接到调音台。

### 头戴式话筒

带腰包的头戴麦，主持人或边跳边唱的歌手用。不用手拿：戴着或放在背包任意位置时都会发射。

**配方**（得 1 个）：

```
S . S
. I .
R G R
```

S = 线，I = 铁锭，R = 红石粉，G = 荧石粉。

| 操作 | 作用 |
|---|---|
| 右键 | 戴到头上 |
| 潜行 + 右键 | 切到下一个通道（1-16） |

戴着的话筒没有静音。想不出声，就摘下来放进箱子，或者调到没有接收器使用的通道。身上有好几支麦时，
优先用手上的，其次是戴着的，最后是背包里的。

**常见接法**：调到某台[无线接收器](#无线接收器)的通道。

### 领夹话筒

带腰包的小型领夹麦，话剧和演讲常用。用法和[头戴式话筒](#头戴式话筒)一样，只是戴在胸前。

**配方**（得 1 个）：

```
. I .
. S .
R G R
```

I = 铁锭，S = 线，R = 红石粉，G = 荧石粉。

| 操作 | 作用 |
|---|---|
| 右键 | 戴到胸前 |
| 潜行 + 右键 | 切到下一个通道（1-16） |

戴着或带在身上时都会发射。戴着的话筒没有静音。

**常见接法**：调到某台[无线接收器](#无线接收器)的通道。

### 无线接收器

无线麦的接收机。它接收 128 格内同通道的所有无线麦、头戴麦和领夹麦，把声音送进线缆。

**配方**（得 1 个）：

```
L . L
I R I
I I I
```

L = 避雷针，I = 铁锭，R = 红石粉。

**摆放**：一个比方块小的矮盒子，放在桌上或机柜里。正面朝向你。

**控件**（正面面板）：

| 控件 | 作用 |
|---|---|
| 通道显示屏 | 右键：下一个通道 |
| - 按钮 | 上一个通道 |
| + 按钮 | 下一个通道 |

**接口**：

| 接口 | 方向 | 位置 |
|---|---|---|
| OUT | 输出 | 背面 |

**常见接法**：用 [XLR 话筒线](#xlr-话筒线)把 OUT 接到调音台 IN，或接到[舞台接口箱](#舞台接口箱-8-路)、
[墙面接口](#墙面接口)。一支麦配一台接收器，各用各的通道。

### 立式有线麦克风

装在落地支架上的有线人声麦。拾取 3 格内说话的玩家。

**配方**（得 1 个）：

```
. M .
. I .
I I I
```

M = 无线麦克风，I = 铁锭。

**摆放**：一格，立在地上。没有控件。

**接口**：

| 接口 | 方向 | 位置 |
|---|---|---|
| OUT | 输出 | 任意一面：右键话筒任何地方都行 |

**常见接法**：用 [XLR 话筒线](#xlr-话筒线)接到调音台 IN 或舞台接口箱的 CH 接口。

### 鹅颈会议话筒

讲台或会议桌上那种细长话筒。拾取 2 格内的玩家。

**配方**（得 1 个）：

```
. . I
S I .
I I I
```

I = 铁锭，S = 线。

**摆放**：一格，放在讲台或桌上。没有控件。

**接口**：OUT，任意一面（右键话筒任何地方）。

**常见接法**：用 [XLR 话筒线](#xlr-话筒线)接到调音台 IN。

### 吊挂合唱话筒

吊在合唱团或舞台上一组人上方的话筒。拾取 8 格内的玩家。

**配方**（得 1 个）：

```
. C .
. I .
. R .
```

C = 锁链，I = 铁锭，R = 红石粉。（放在任意一列都行。）

**摆放**：一格，放在演唱者上方，比如天花板或桁架下面。人可以从中穿过。没有控件。

**接口**：OUT，任意一面（右键话筒任何地方）。

**常见接法**：用 [XLR 话筒线](#xlr-话筒线)沿天花板上的[线卡](#线卡)接到调音台 IN。

### 媒体播放机

播放进场音乐和音效的播放机。播放 `venuesound_media` 文件夹里的 `.mp3` 和 `.wav` 文件（文件夹在
`mods/` 旁边；服务器上在服务器文件夹里）。

**配方**（得 1 个）：

```
I I I
R J R
I I I
```

I = 铁锭，R = 红石粉，J = 唱片机。

**摆放**：半格高，放在桌上或机柜里。正面朝向你。

**控件**（正面面板，显示屏下方从左到右）：

| 控件 | 作用 |
|---|---|
| 显示屏 | 显示曲目和是否在播放 |
| Prev | 上一首 |
| Play | 播放 |
| Stop | 停止 |
| Next | 下一首 |
| Loop | 循环开 / 关 |
| 潜行 + 右键播放机 | 打开曲目列表 |

**接口**：

| 接口 | 方向 | 位置 |
|---|---|---|
| OUT | 输出 | 背面 |

**常见接法**：OUT 接调音台 IN（单声道通道，或经过 [DI 盒](#di-盒)）。

### 视频采集器

把 WATERFrAMES 屏幕的声音接进调音台。采集区里的屏幕音量跟着调音台的推子和静音走，离音箱近就大声。
（屏幕的声音是在每个玩家自己的电脑上播放的，所以没法真的从音箱方向传来。）

**配方**（得 1 个）：

```
I G I
R C R
I I I
```

I = 铁锭，G = 荧石粉，R = 红石粉，C = 红石比较器。

**摆放**：一格，正面朝向你。没有控件，采集区用[区域选择器](#区域选择器)设置。

**接口**：

| 接口 | 方向 | 位置 |
|---|---|---|
| OUT | 输出 | 背面 |

**常见接法**：OUT 接调音台 IN。

## 调音

### 调音台 VS-12

调音位的主调音台：8 个单声道通道、2 个立体声通道（第一个立体声通道 ST1，即 9/10 路，是内置的
USB 播放器），加一个总控区。所有控件都在台面上。每个控件对声音的作用见[调音台](console.md)（英文）。

**配方**（得 1 台）：

```
L C L
R Q R
I I I
```

L = 拉杆，C = 红石比较器，R = 红石粉，Q = 下界石英，I = 铁锭。

**摆放**：3 格宽、2 格深、半格高。你站在正面（调音师这一侧）。你点的那一格成为左前角，调音台向你
右边延伸 3 格、向远离你的方向延伸 2 格，这些位置要空着。打掉任何一格，整台调音台都会被拆掉。

**控件**（台面，每个通道从后往前）：

| 控件 | 范围 | 用法 |
|---|---|---|
| GAIN | 0-2，默认 1 | 旋钮 |
| HI / MID / LOW | ±12 dB，每档 2 dB | 旋钮 |
| AUX1 / AUX2 | 0-1 | 旋钮：送到 AUX 1 / AUX 2 |
| EFX | 0-1 | 旋钮：送到效果器 |
| PAN | 左 - 右 | 旋钮 |
| PEAK | | 指示灯 |
| MUTE | 开 / 关 | 按钮 |
| PFL | 开 / 关 | 按钮 |
| 推子 | 0-2，中间刻度 = 0 dB | 按住拖动，或滚轮 |

总控区（最右边）：USB PLAYER 显示屏，旁边的 DELAY 旋钮（效果回声时间）和 PHONES 旋钮，USB 按钮
|<（上一首）、>（播放）、[]（停止）、>|（下一首），左右电平表，以及 EFX（效果返回）、AUX1、AUX2、
L、R（主输出）推子。

旋钮和推子都可以用鼠标滚轮调（推子每格 0.1）。

**接口**：在背面（朝向舞台的一侧），每路输入在它那一条通道的正后方。

| 接口 | 方向 | 位置 |
|---|---|---|
| IN 1 - IN 8 | 输入 | 背面，第 1-8 路通道后方 |
| IN 11/12 | 输入 | 背面，第二个立体声通道后方 |
| MAIN L、MAIN R | 输出 | 背面，总控区后方 |
| AUX 1、AUX 2 | 输出 | 背面，总控区后方 |

第一个立体声通道（9/10）是 USB 播放器，没有接口。每个输出只能接一根线。

**常见接法**：话筒、接收器、舞台接口箱的多芯缆、媒体播放机接 IN；MAIN L / MAIN R 接功放的
IN A / IN B（或先经过机架处理器）；AUX 1 / AUX 2 接带返听音箱的功放，或接
[入耳监听发射机](#入耳监听发射机)。

### 调音台 VS-24

大一号的调音台：16 个单声道通道、4 个立体声通道。控件和 [VS-12](#调音台-vs-12) 一样。

**配方**（无序合成，得 1 台）：2 台调音台（VS-12）。

**摆放**：5 格宽、2 格深。你点的那一格是左前角，向你右边延伸 5 格、向远处延伸 2 格。

**控件**：和 VS-12 相同，共 20 条通道。第一个立体声通道（17/18）是 USB 播放器。

**接口**（背面，朝向舞台，每路输入在它的通道正后方）：

| 接口 | 方向 | 位置 |
|---|---|---|
| IN 1 - IN 16 | 输入 | 背面，第 1-16 路通道后方 |
| IN 19/20、IN 21/22、IN 23/24 | 输入 | 背面，立体声通道后方 |
| MAIN L、MAIN R、AUX 1、AUX 2 | 输出 | 背面，总控区后方 |

**常见接法**：同 VS-12。一根 [16 路舞台接口箱](#舞台接口箱-16-路)的多芯缆就能一次接满 IN 1-16。

## 机架设备

### 功放机

推动音箱。**IN A** 送到 **OUT 1** 和 **OUT 2**，**IN B** 送到 **OUT 3** 和 **OUT 4**，音量按正面的
电平旋钮放大。放下时就是开机状态。

**配方**（得 1 台）：

```
I I I
B C B
I I I
```

I = 铁锭，B = 红石块，C = 红石比较器。

**摆放**：一格，放在机柜里。正面朝向你，接口在背面。

**控件**（正面面板）：

| 控件 | 作用 |
|---|---|
| 翘板开关 | 电源开 / 关 |
| 电平旋钮 | 25 % 到 200 %，每档 25 %（默认 100 %）。点左半边调小、右半边调大；按住会一直转；也可用滚轮 |

**接口**：

| 接口 | 方向 | 位置 |
|---|---|---|
| IN A、IN B | 输入 | 背面，上排 |
| OUT 1 - OUT 4 | 输出 | 背面，下排 |

**常见接法**：调音台 MAIN L → IN A，MAIN R → IN B；用[音箱线](#音箱线)把 OUT 1 → 左音箱，
OUT 3 → 右音箱。每个 OUT 只能接一根线。

### 图示均衡器

7 段均衡器，用来按场地调整整套系统的音色。串在线路中间，一般在调音台和功放之间。

**配方**（得 1 台）：

```
I G I
R C R
I I I
```

I = 铁锭，G = 荧石粉，R = 红石粉，C = 红石比较器。

**摆放**：一格，放在机柜里。正面朝向你。

**控件**（正面面板）：

| 控件 | 作用 |
|---|---|
| 推杆 63、160、400、1K、2.5K、6.3K、16K | ±12 dB，每档 3 dB。点上半部分提升，点下半部分衰减；也可用滚轮 |
| 翘板开关 | 电源。关机时信号不通过 |
| 电平旋钮 | 输出电平，25 % 到 200 % |

**接口**（和功放一样，都在背面）：IN A、IN B（输入）；OUT 1 - OUT 4（输出）。两个输入都会送到全部
四个输出。

**常见接法**：调音台 MAIN L → IN A，再从 OUT 1 → 功放 IN A。

### 压缩限幅器

把忽大忽小的声音拉平，并压住突然的峰值。和均衡器一样串在线路中。

**配方**（得 1 台）：

```
I R I
R C R
I I I
```

I = 铁锭，R = 红石粉，C = 红石比较器。

**摆放**：一格，放在机柜里。正面朝向你。

**控件**（正面面板）：

| 控件 | 作用 |
|---|---|
| THRESH 旋钮 | 0.1-1，默认 0.5。越低，被压缩的部分越多 |
| RATIO 旋钮 | 1-10，默认 4 |
| 翘板开关 | 电源 |
| 电平旋钮 | 输出电平 |

旋钮点左半边调小、右半边调大，或用滚轮。

**接口**（背面）：IN A、IN B（输入）；OUT 1 - OUT 4（输出）。

**常见接法**：串在调音台输出和功放之间，或话筒和调音台输入之间。

### 效果器

给人声和讲话加回声的效果器。串在线路中。

**配方**（得 1 台）：

```
I E I
R C R
I I I
```

I = 铁锭，E = 末影珍珠，R = 红石粉，C = 红石比较器。

**摆放**：一格，放在机柜里。正面朝向你。

**控件**（正面面板）：

| 控件 | 作用 |
|---|---|
| MIX 旋钮 | 回声量，0-1，默认 0.4 |
| TIME 旋钮 | 回声时间，0-1，默认 0.4 |
| 翘板开关 | 电源 |
| 电平旋钮 | 输出电平 |

**接口**（背面）：IN A、IN B（输入）；OUT 1 - OUT 4（输出）。

**常见接法**：串在调音台和功放之间。（调音台本身也有 EFX 发送和回声。）

### 分频器与音箱处理器

把信号分给超低音和全频音箱。每一路馈送用一台分频器。

**配方**（得 1 台）：

```
I C I
R C R
I I I
```

I = 铁锭，C = 红石比较器，R = 红石粉。

**摆放**：一格，放在机柜里。正面朝向你。

**控件**（正面面板）：

| 控件 | 作用 |
|---|---|
| FULL/LOW/HIGH 旋钮 | FULL：全部通过。LOW：只留低频（给超低音）。HIGH：切掉低频（给全频音箱） |
| 翘板开关 | 电源 |
| 电平旋钮 | 输出电平 |

**接口**（背面）：IN A、IN B（输入）；OUT 1 - OUT 4（输出）。

**常见接法**：调音台 MAIN → 设为 LOW 的分频器 → 功放 → [超低音音箱](#超低音音箱)；另一台设为
HIGH 的分频器 → 功放 → 全频音箱。

### 电源时序器

按安全顺序开关整套系统：开机时先开音箱、最后开功放；关机时先关功放。每一步间隔 4 tick。

**配方**（得 1 台）：

```
I L I
R C R
I I I
```

I = 铁锭，L = 拉杆，R = 红石粉，C = 红石比较器。

**摆放**：一格，放在机柜里。正面朝向你。

**控件**：右键它。只要 16 格内有任何一台功放开着，就把 16 格内所有功放和音箱关掉；否则全部打开。
处理器不受它控制。

**接口**：无。

### 机柜

用来放功放和处理器的机柜。只是外观，不传信号。

**配方**（得 1 个）：

```
I I I
I . I
I I I
```

I = 铁锭。

**摆放**：一格，正面朝向你。没有控件和接口。

## 音箱

每台音箱的**背板**上都有 **INPUT** 接口、**电源开关**和**覆盖范围旋钮**。覆盖范围就是能听到它的
距离：16、32、48、64（默认）、96 或 128 格。点旋钮左半边调小、右半边调大，或用滚轮。音箱放下时
是开着的。音箱只播放通过线缆送到 INPUT 的声音。

### 线阵音箱模块

小型线阵音箱，用作主扩或侧补。

**配方**（得 1 个）：

```
I I I
N J N
I I I
```

I = 铁锭，N = 音符盒，J = 唱片机。

**摆放**：一格。正面（网罩）朝向你，所以站在观众的位置放下它，背板就朝向远离你的一侧。

| 接口 / 控件 | 方向 | 位置 |
|---|---|---|
| INPUT | 输入 | 背面 |
| 电源开关、覆盖范围旋钮 | | 背面 |

**常见接法**：用[音箱线](#音箱线)从功放 OUT → INPUT。

### 吊挂线阵音箱

吊在舞台上方的线阵单元。

**配方**（得 1 个）：

```
. C .
P N P
P P P
```

C = 锁链，P = 任意木板，N = 音符盒。

**摆放**：一格，不需要支撑；放在[桁架吊点](#桁架吊点)下面，看起来就是吊着的。正面朝向你。

| 接口 / 控件 | 方向 | 位置 |
|---|---|---|
| INPUT | 输入 | 背面 |
| 电源开关、覆盖范围旋钮 | | 背面 |

**常见接法**：用[音箱线](#音箱线)沿桁架上的[线卡](#线卡)从功放 OUT → INPUT。

### 桁架吊点

挂吊挂音箱用的吊点。只是外观，不传信号。

**配方**（得 1 个）：

```
I C I
. C .
```

I = 铁锭，C = 锁链。

**摆放**：一格，放在高处，吊挂音箱放在它下面。没有控件和接口。

### 大型 PA 音箱

全频 PA 音箱（下面是低音单元，上面是号角），小场地常用的主音箱。

**配方**（得 1 个）：

```
I S I
W S W
I S I
```

I = 铁锭，S = 线阵音箱模块，W = 黑色羊毛。

**摆放**：2 格高，上方要有一格空位。正面朝向你。打掉上下任意一半都会拆掉整台。

| 接口 / 控件 | 方向 | 位置 |
|---|---|---|
| INPUT | 输入 | 背面，下半部分 |
| 电源开关、覆盖范围旋钮 | | 背面，下半部分 |

**常见接法**：功放 OUT 1 → 左音箱，OUT 3 → 右音箱。

### 大型演唱会音箱

体育场级的大型音箱堆：顶部是号角阵列，中间是 15 寸中低音单元，底部是 18 寸超低音。

**配方**（得 1 个）：

```
P P P
P A P
P P P
```

P = 大型 PA 音箱，A = 功放机。

**摆放**：4 格宽、6 格高、2 格深。正面朝向你。你点的那一格是你看到的左下角，音箱向你右边延伸
4 格、向上 6 格、向远处 2 格。打掉任何一格都会拆掉整个音箱堆。

| 接口 / 控件 | 方向 | 位置 |
|---|---|---|
| INPUT | 输入 | 背面底部，你放置的那个角的正后方 |
| 电源开关、覆盖范围旋钮 | | 同一位置 |

**常见接法**：用[音箱线](#音箱线)从功放 OUT → INPUT。舞台两边各放一个。

### 地板返听音箱

放在舞台地板上的矮斜面音箱，朝向表演者，让他们听到自己的声音。

**配方**（得 1 个）：

```
P N P
P R P
P P P
```

P = 任意木板，N = 音符盒，R = 红石粉。

**摆放**：比半格稍高，放在舞台地板上。正面朝向你，所以要站在表演者的位置放下它。

| 接口 / 控件 | 方向 | 位置 |
|---|---|---|
| INPUT | 输入 | 背板 |
| 电源开关、覆盖范围旋钮 | | 背板 |

**常见接法**：调音台 AUX 1 → 功放 IN → 功放 OUT → INPUT。覆盖范围调低（16），观众就听不到。

### 超低音音箱

补充低频的音箱，一般放在主音箱下面或旁边的地上。

**配方**（得 1 个）：

```
P N P
N R N
P N P
```

P = 任意木板，N = 音符盒，R = 红石粉。

**摆放**：一格，放在地上。正面朝向你。

| 接口 / 控件 | 方向 | 位置 |
|---|---|---|
| INPUT | 输入 | 背面 |
| 电源开关、覆盖范围旋钮 | | 背面 |

**常见接法**：功放 OUT → INPUT。要真正的超低音馈送，在它的功放前面加一台设为 LOW 的
[分频器](#分频器与音箱处理器)。

### 入耳监听发射机

把返听混音通过无线发给表演者的耳机。只有带着**同频道**[入耳监听耳机](#入耳监听耳机)的玩家能听到，
范围至少 128 格。每个混音用一台发射机：比如主唱的耳机和发射机都设频道 1，接 AUX 1；鼓手的设频道 2，
接 AUX 2。

**配方**（得 1 台）：

```
I E I
R C R
```

I = 铁锭，E = 末影珍珠，R = 红石粉，C = 红石比较器。

**摆放**：一个小矮盒子，放在桌上或机柜里。正面朝向你。

| 接口 / 控件 | 方向 | 位置 |
|---|---|---|
| INPUT | 输入 | 背板 |
| 电源开关、覆盖范围旋钮 | | 背板 |
| 频道显示、− / + 按钮 | | 正面：按 − 或 + 切换频道（1–16）；点显示屏也会加一 |

**常见接法**：调音台 AUX 1 或 AUX 2 → INPUT（直接接，或经过功放）。

### 入耳监听耳机

表演者用的耳机，配合[入耳监听发射机](#入耳监听发射机)。

**配方**（得 1 个）：

```
S . S
I . I
G . G
```

S = 线，I = 铁锭，G = 荧石粉。

**用法**：放在背包任意位置，就能听到同频道的入耳监听发射机。不能放置。

| 操作 | 作用 |
|---|---|
| 右键 | 下一个频道（1–16），物品提示里显示当前频道 |
| 潜行+右键 | 上一个频道 |

## 内通

工作人员之间的对讲系统：导演、舞台监督、灯光、音响戴着耳麦互相说话，观众听不到，也不经过调音台。

### 内通主站

内通的核心。腰包只在主站的覆盖范围内工作。接进它节目输入（PGM IN）的声音（通常是调音台的 MAIN
或某个 AUX）会播给附近所有腰包，让工作人员跟上演出。

**配方**（得 1 台）：

```
I N I
R C R
I I I
```

I = 铁锭，N = 音符盒，R = 红石粉，C = 红石比较器。

**摆放**：半格高的盒子，放在桌上或机柜里。正面朝向你。

| 接口 / 控件 | 方向 | 位置 |
|---|---|---|
| PGM IN | 输入 | 背板 |
| 电源开关 | | 背板：点击开 / 关 |
| 覆盖范围旋钮 | | 背板：16–128 格（点左右半边或用滚轮）。腰包必须在范围内 |

**常见接法**：调音台 AUX → PGM IN（可选）。主站不通电时整个内通都没声音。

### 内通腰包

工作人员的腰包和耳麦，放在背包任意位置即可。

**配方**（得 1 个）：

```
S L S
I R I
```

S = 线，L = 皮革，I = 铁锭，R = 红石粉。

| 操作 | 作用 |
|---|---|
| 右键 | 切换通道 A / B |
| 潜行+右键 | TALK 开 / 关。打开后，同通道带腰包的人都能听到你 |

你总能听到同通道正在说话的人和主站的节目声。说话的人和听的人都要在通电主站的覆盖范围内、同一个维度。
两个通道可以让两组人同时工作，比如 A 给舞台监督，B 给灯光。

## 线材与跳线

### 线材通用用法

1. 拿着线右键一个 **OUT** 接口。一端插上，线连到你手上。
2. 可以依次右键几个[线卡](#线卡)，让线沿着它们走。
3. 右键一个 **IN** 接口，插上另一端。

| 操作 | 作用 |
|---|---|
| 潜行 + 右键接口 | 拔掉这个接口上的线 |
| 潜行 + 右键空气 | 放下手里拿着的那一端 |

线材不会被用掉：一件线材可以接任意多根线。长度限制按每一段算（接口到线卡、线卡到线卡、线卡到接口）。
会穿过墙的线会被拒绝，用线卡绕过去。

| 线材 | 能接什么 | 每段长度 | 颜色 |
|---|---|---|---|
| [音频线](#音频线) | 任何接口 | 64 格 | 黑色 |
| [XLR 话筒线](#xlr-话筒线) | 话筒和线路信号；不能从功放输出接出 | 96 格 | 深蓝色 |
| [音箱线](#音箱线) | 只能从功放 OUT 到音箱 INPUT（中间可以经过墙面接口） | 96 格 | 橙色 |
| [多芯信号缆](#多芯信号缆) | 只能从舞台接口箱的 SNAKE 接口到调音台（或墙面接口） | 128 格 | 粗黑色 |
| [线缆卷盘](#线缆卷盘) | 任何接口 | 128 格 | 黄色 |

### 音频线

通用线，什么都能接。

**配方**（得 1 根）：

```
S . .
. R .
. . S
```

S = 线，R = 红石粉。

每段 64 格，显示为黑色。

### XLR 话筒线

标准话筒线。用于话筒、接收器、媒体播放机，以及调音台输出到处理器和功放。不能从功放的输出接出，
那里要用音箱线。

**配方**（得 1 根）：

```
. W .
. R .
. W .
```

W = 黑色羊毛，R = 红石粉。（放在任意一列都行。）

每段 96 格，显示为深蓝色。

### 音箱线

从功放到音箱的粗线。只能从功放 OUT 接到音箱 INPUT，中间可以经过[墙面接口](#墙面接口)。

**配方**（得 1 根）：

```
. W .
. C .
. W .
```

W = 黑色羊毛，C = 红石比较器。（放在任意一列都行。）

每段 96 格，显示为橙色。

### 多芯信号缆

从舞台到调音位的粗多芯缆。只能从舞台接口箱的 **SNAKE** 接口接到调音台输入（中途可以经过墙面接口）。

**配方**（得 1 根）：

```
W W W
R C R
W W W
```

W = 黑色羊毛，R = 红石粉，C = 红石比较器。

每段 128 格，显示为粗黑色。调音台一端插 **IN 1**：接口箱 CH 1 进 IN 1，CH 2 进 IN 2，依此类推
（会跳过 USB 通道）。

### 线缆卷盘

绕在线盘上的长通用线，用于长距离布线。什么都能接。

**配方**（得 1 个）：

```
P W P
W C W
P W P
```

P = 任意木板，W = 黑色羊毛，C = 红石比较器。

每段 128 格，显示为黄色。

### 线卡

把线固定在墙、地板或天花板上的小卡子，让线沿着建筑走，而不是横穿房间。

**配方**（得 8 个）：

```
N . N
N N N
```

N = 铁粒。

**摆放**：右键任意方块的任意一面（空气和液体不行），它就贴在那一面上。人可以从中穿过。

**用法**：拿着一端已经插好的线，依次右键线卡，最后右键 IN 接口。每个线卡是线路的一个拐点，两个线卡
之间的每一段最长可以到这种线材的每段长度。

### 墙面接口

无源跳线点：一块带四个接口的面板，就像连接舞台和控制室的墙面接线盒。线可以接进来，再接到其他墙面
接口、调音台、功放或音箱。一个墙面接口也可以把一路信号分给好几根线。

**配方**（得 4 个）：

```
N N N
N R N
N N N
```

N = 铁粒，R = 红石粉。

**摆放**：右键墙面，面板就贴在那面墙上，朝外。放在地板或天花板上时朝向你。

**接口**（面板上）：

| 接口 | 方向 | 位置 |
|---|---|---|
| S1、S2、S3、S4 | 输入或输出（每个接口两种都行） | 正面（面板） |

一个墙面接口最多可以接出 8 根线。

**常见接法**：舞台上接收器 OUT → 舞台墙上墙面接口的 S1；同一个墙面接口的 S2 → 控制室墙面接口的 S1；
控制室那个接口的 S2 → 调音台 IN。音箱线可以经过墙面接口。

### 舞台接口箱 8 路

放在舞台上的接口箱，收集最多 8 支话筒，用一根[多芯信号缆](#多芯信号缆)送到调音台。

**配方**（得 1 个）：

```
I I I
W C W
I I I
```

I = 铁锭，W = 黑色羊毛，C = 红石比较器。

**摆放**：和墙面接口一样：放在墙上时朝外；放在地上时朝向你。

**接口**（都在正面）：

| 接口 | 方向 | 位置 |
|---|---|---|
| CH 1 - CH 8 | 输入 | 正面，两排各四个 |
| SNAKE | 输出 | 正面，底部 |

**常见接法**：用 [XLR 话筒线](#xlr-话筒线)把话筒接到 CH 1-8；用多芯信号缆把 SNAKE 接到调音台 IN 1。
CH 1 进多芯缆插入的那一路输入，CH 2 进下一路，依此类推。

### 舞台接口箱 16 路

16 路舞台接口箱，配合 [VS-24](#调音台-vs-24) 使用。

**配方**（得 1 个）：

```
W I W
W C W
W I W
```

W = 黑色羊毛，I = 铁锭，C = 红石比较器。

**摆放**：和 8 路接口箱一样。

**接口**（正面）：CH 1 - CH 16（输入，两排各八个）；SNAKE（输出，底部）。

**常见接法**：话筒 → CH 1-16；SNAKE → VS-24 的 IN 1。

### DI 盒

直插盒：把线路电平的信号源（媒体播放机、键盘）送进话筒输入。它按电平设置把信号传下去。

**配方**（得 1 个）：

```
I . I
R C R
I I I
```

I = 铁锭，R = 红石粉，C = 红石比较器。

**摆放**：一格，放在舞台地板上或机柜里。正面朝向你。

**控件**（正面面板）：翘板开关（电源），电平旋钮（25 % 到 200 %）。

**接口**（背面）：IN A、IN B（输入）；OUT 1 - OUT 4（输出）。

**常见接法**：媒体播放机 OUT → DI 的 IN A；DI 的 OUT 1 → 舞台接口箱 CH 或调音台 IN。

## 工具

### 区域选择器

**配方**（得 1 个）：

```
. . I
. I .
```

G = 荧石粉，I = 铁锭。
