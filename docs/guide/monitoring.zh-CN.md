# 监听与内通

台上的人怎么听到自己，演出时工作人员怎么互相说话。

## 地板返听音箱

返听音箱放在舞台地面上、朝着演员，播放的是 AUX 混音，不是主扩混音。

1. 在演员面前放一台**地板返听音箱**，面朝演员。
2. 从调音台背面的 **AUX 1** 插孔接到功放的输入，功放 OUT 再用音箱线接到返听箱的 **INPUT**。AUX 1
   也可以直接接返听箱。
3. 在每一路上调 **AUX 1** 旋钮，决定这一路有多少声音进返听。主唱通常想多听自己。
4. 总控区的 **AUX 1** 推子控制返听总音量。
5. 打开返听箱背面的电源，调小它的覆盖范围，免得观众听到返听。

AUX 在推子之前送出：台下推子拉低，返听不受影响。MUTE 会让这一路在所有地方都静音。AUX 2 是第二路
独立的混音。

## 入耳监听

入耳监听只有带着耳机的人能听到，所以每个演员可以有自己的混音。

1. 放一台**入耳监听发射机**，把调音台的某个 AUX 接到它的 **INPUT**，打开电源。
2. 点击它的正面选择频道（1–16，正面会显示）。
3. 给演员一副设成同一频道的**入耳监听耳机**（右键耳机切换频道），放在背包里任何位置都行。
4. 第二个演员想要不同的混音，就用另一台发射机、另一个频道，接 AUX 2。

例子：主唱用频道 1，接 AUX 1；鼓手用频道 2，接 AUX 2。

## 内通

内通让导演、舞台监督、灯光、音响在演出中戴着耳麦互相说话。观众听不到，也不经过调音台。

1. 放一台**内通主站**，在背板打开电源。覆盖范围旋钮（16–128 格）决定腰包离主站多远还能用。
2. 给每个工作人员一个**内通腰包**，右键选择通道 **A** 或 **B**。
3. 要说话时，**潜行+右键**腰包打开 **TALK**，正常说话即可。同通道带腰包的人，只要在主站覆盖范围内，
   都能听到你。关掉 TALK 就是只听不说。
4. 可选：把调音台的某个 AUX（或 MAIN）接到主站的 **PGM IN**，主站附近所有腰包就能同时听到演出，
   方便工作人员跟进。

两个通道可以让两组人同时工作，比如 A 给舞台监督，B 给灯光。打开 TALK 时，旁边的玩家仍然能通过
普通语音听到你，和平时说话一样。

配方和每个控件见[物品大全](items.zh-CN.md#内通)。
